# 📊 Sales Data Analysis Dashboard (Excel)

## 📌 Project Overview

This project presents an interactive Sales Dashboard built in Microsoft Excel to analyze sales performance and provide business insights. The dashboard helps track key sales metrics, monitor product performance, evaluate regional sales, and identify trends to support data-driven decision-making.

---

## 🎯 Objectives

- Analyze overall sales performance.
- Monitor monthly sales trends.
- Compare sales across different regions.
- Identify top-selling products and categories.
- Track customer purchasing behavior.
- Provide interactive reports using slicers and PivotTables.

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- XLOOKUP
- IF, IFS, SUMIFS, COUNTIFS
- Data Validation
- Charts & Graphs
